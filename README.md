# Student Management System

A simple and practical Student Management System developed using Python and JSON.

## About the Project

This project is a console-based application that helps manage student records. It allows users to add, view, search, update, and delete student information.

Student records are stored in a JSON file, so the data remains available even after closing and restarting the program.

## Features

- Add New Student
- View All Students
- Search Student by ID
- Update Student Details
- Delete Student Records
- Prevent Duplicate Student IDs
- Validate Student Name, Age, and Course
- Save and Load Data Using JSON
- Data Persistence

## Technologies Used
